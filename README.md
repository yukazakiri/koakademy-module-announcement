# KoAkademy Announcement Module

School-wide announcements for administrators and portal users.

## Installation

```sh
composer require koakademy/announcement:^1.0
```

This package targets KoAkademy 1.20+, PHP 8.5, Laravel 13, Filament 5, and
`nwidart/laravel-modules` 13. It is licensed under AGPL-3.0-or-later.

The package is discovered through Laravel's provider metadata and the
KoAkademy module manifest. Run the host application's migrations after
installation.
